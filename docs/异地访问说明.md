# 让异地同事用上工作台（当前：客服主管试用客服质检）

> 一句话：你双击一个文件，窗口里会出现一个网址；把网址和账号发给她，她就能在异地用浏览器打开。

---

## 一、你这边的操作（3 步）

1. 打开项目文件夹，双击 **`启动工作台-远程.command`**
   （如果 macOS 提示"无法验证开发者"，右键点它 → 选"打开" → 再点"打开"）
2. 等窗口出现 **`✅ 远程访问已就绪`**，下面会有一行网址，形如：

   ```
   https://xxxx-xxxx-xxxx-xxxx.trycloudflare.com/quality.html
   ```

   这个网址已经自动复制到剪贴板，直接粘贴发给同事即可。
3. **窗口不要关**。关掉窗口 = 关站，她那边就打不开了。

窗口里会显示她要用的账号和密码（同一份信息也存在项目里的 `本地账号.txt`，那个文件不进 git）。

---

## 二、同事那边的操作

1. 浏览器打开你发的网址
2. 输入你发给她的账号和密码（就是脚本窗口里显示的那两行，也记在项目根目录的 `本地账号.txt`）
3. 登录后直接进「客服质检」页，能看到 703 条历史会话、评分和待复核列表

建议她把这个网址加到浏览器收藏夹，或者手机浏览器"添加到主屏幕"。

---

## 三、必须知道的 3 个限制

| 限制 | 说明 |
|---|---|
| **你的电脑必须开着** | 服务跑在你这台 Mac 上。关机、合盖、断网，她那边就打不开。脚本已自动阻止电脑空闲睡眠，但**合上笔记本盖仍然会断**。 |
| **网址每次重启会变** | 免费通道的地址是随机的。你重新双击启动，就会得到一个新网址，需要重新发给她。只要窗口一直开着、地址就不变。 |
| **你自己电脑打不开这个网址是正常的** | 你本机 DNS 会缓存"域名不存在"，等 5 分钟或换个浏览器就行。**不影响她**，她那边是干净的网络。 |

---

## 四、安全提醒（重要）

1. **这个网址是公网可访问的**——任何拿到链接的人都能看到登录页。请只发给该发的人，别发到群里。
2. **管理员账号还是默认弱密码**（`admin` / `Workbench@2026`）。现在系统对外开了口子，建议尽快改掉：
   登录后点右上角账号 → 账号安全 → 改密码。
3. 主管账号 `kfzg` 的角色是「运营」，能看到销售、库存等其他模块，不只是质检。如果你希望她**只能看质检**，告诉我，我给她单独收窄权限。
4. 她试用过程中的导入、复核操作会**真实写入**你的数据库。如果只是想让她熟悉流程、不想动真实数据，先跟她说清楚别点「确认导入」。

## 五、试用之后，如果要长期/多人用

现在这套是"借你的电脑当服务器"，适合试用 1～2 周。如果她用得顺手、要让团队长期用，有两条升级路：

### 路线 A：买一台国内云服务器（推荐，约 ¥30～60/月）

- 优点：7×24 在线，你电脑关机也不影响；国内机房，打开最快；数据在你自己的服务器上
- 做法：腾讯云/阿里云买台"轻量应用服务器"（2核2G 起步），我把项目打包成 Docker，你跟着我发的步骤复制粘贴命令，20 分钟上线
- 用公网 IP 访问**不需要备案**

### 路线 B：固定网址的穿透服务（约 ¥9/月起）

- 适合"还是想跑在自己电脑上，但想要一个不变的网址"
- 国内服务商（如 cpolar、natapp）付费版给固定二级域名，速度也比现在的免费通道快

两条路都不影响现有数据，随时可以切。

---

## 六、出问题怎么办

| 现象 | 处理 |
|---|---|
| 窗口里没出现网址 | 看窗口最后几行的报错，截图发给助手 |
| 她说"打不开" | 先确认你这边窗口还开着、没断网；再把最新网址重新发她一次 |
| 页面能开但登录转圈 | 你本机服务可能挂了，关掉窗口重新双击一次 |
| 提示"数据库启动失败" | 打开 Docker Desktop，等它起来后重新双击脚本 |
