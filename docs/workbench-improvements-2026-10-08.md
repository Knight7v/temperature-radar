## 备份运行与恢复

先配置 `DATABASE_URL`，运行 `npm run db:backup`。本机使用Docker数据库时另设置 `DB_BACKUP_CONTAINER=codex-workbench-test-db`；容器内须支持当前数据库用户的本地认证。备份默认保存到被Git忽略的 `backups/`，可通过 `BACKUP_DIR` 指定目录。原生方式需安装匹配服务端版本的 `pg_dump` 和 `pg_restore`。

恢复时首先校验SHA256，使用 `pg_restore --no-owner --no-acl --exit-on-error` 恢复至新建的独立数据库，并核查表、记录及业务查询。不要直接覆盖现用数据库。归档包含业务数据和认证记录，应限制访问。
