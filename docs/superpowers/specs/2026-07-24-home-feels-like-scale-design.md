# 首页体感温度色阶调整设计

**日期：** 2026-07-24

## 目标

调整首页地图“体感温度”模式的显示量程与颜色规则，使温度档位准确、颜色随温度升高逐渐加深。

## 范围

仅修改首页地图的体感温度模式，包括：

- 地图体感温度量程
- 体感温度图例
- 地图圆点颜色
- 地图悬浮提示中的体感温度颜色

不修改 ADI、夜间温度、白天最高温、七日预测或城市详情中的业务规则。

## 色阶规则

首页体感温度显示上限由 50°C 调整为 45°C，边界严格按“超过”处理：

| 温度范围 | 色系 | 渐变方式 |
| --- | --- | --- |
| ≤26°C | 低温色 | 随温度升高由青蓝向较深蓝色过渡 |
| 27–35°C | 黄色 | 在黄色系内逐渐加深 |
| 36–40°C | 橙色 | 在橙色系内逐渐加深 |
| ≥41°C | 红色 | 在红色系内逐渐加深，45°C 达到最深 |

低于量程下限的值按最低颜色显示；高于 45°C 的值按最深红色显示。

## 实现设计

在 `js/map.js` 中增加单一的体感温度颜色计算函数，以 26°C、35°C、40°C 和 45°C 为关键节点进行分段插值。地图圆点与悬浮提示共同使用该函数，避免同一温度在不同位置显示不同颜色。

体感温度模式的最大值改为 45°C，圆点尺寸归一化同步按 20–45°C 计算。图例文案调整为与严格边界一致的四个业务区间。

## 验证

自动化测试覆盖以下代表值：

- 26°C：低温色
- 27°C、35°C：黄色系
- 36°C、40°C：橙色系
- 41°C、45°C：红色系
- 高于 45°C：保持最深红色

同时运行现有测试，并检查首页体感温度模式的量程、图例、圆点和悬浮提示是否一致。
