## 1. 视觉定位

- **气质**：深蓝科技感、品牌导购海报、信息密集但逐行可扫读。
- **对比方式**：左侧参数名，右侧四款机型；推荐机型用浅蓝灰整列底色，普通机型用深蓝底色。
- **强调顺序**：大标题 → 橙红／米白机型标签 → 商品图 → 推荐理由 → 参数差异 → 品牌落款。
- **图像比例**：主内容约占画布上方 89%；底部保留约 10% 的品牌落款空间。

## 4. 版式与组件

- **安全边距**：左右约 10–12 px；标题区顶部约 40–50 px。
- **主表格**：约 `x=10–1054`、`y=225–1312`；左侧字段栏约 195–200 px，其余为四款机型列。正式重绘时建议统一列宽并严格对齐上下分隔线。
- **标题区**：主标题居中，机型标签位于商品图上方；标题与机型标签之间留足空间，避免光效抢文字。
- **机型标签**：高度约 55–60 px；两端大圆角；橙红与米白交替，形成四列节奏。
- **商品图区**：白色壁挂机照片置于表格上段，保持统一透视和留白；不将文字压在产品主体上。
- **表格**：深蓝与蓝灰交替整列填充；横向细线贯穿全表。参数名与数值都以行居中，长文案最多两行。
- **外框**：低亮度浅蓝描边、约 12–16 px 圆角；避免大面积霓虹描边。
- **底部落款**：居中放真实 GREE 品牌素材与口号，上下留白充足。

## 5. 导出与使用

- 设计源文件建议保留文字、商品图、底色、分隔线为独立图层；不要直接在位图上修改商品参数。
- 顾客转发图可导出 **1080 px 宽 PNG**；商品详情页可按平台容器宽度重排，避免直接缩小密集长图。
- 图片中的型号、APF、功能与营销用语须以产品知识库或品牌官方资料为准。修复图仅可用作视觉参考。
