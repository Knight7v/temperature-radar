# 视觉设计 · AI 作图接入说明

> 面向使用者，不需要技术背景。看完这一页就知道现在能用什么、想用 AI 生成还要做什么。

## 一、现在已经能用的（不花钱、不用配置）

打开「视觉设计 → 商品主图工作室」，三个用途都能直接出图：

| 用途 | 做什么 | 谁用 |
|---|---|---|
| **京东首图** | 纯白底、无文字、商品占比自动算到 78%，四边留白按京东标准（800 图 30px，1200 图 45px） | 每个链接的第 1 张图 |
| **场景副图** | 从 8 张内置场景里挑一个当背景，商品图叠上去 + 写 3 条卖点 | 第 2-5 张副图 |
| **活动图** | 深色氛围背景 + 大标题 + 卖点胶囊标签 | 详情页、活动页 |

配套的三个自动能力：

- **自动裁白边**：拍图时四周留白过多，上传后自动裁到商品边缘，占比才算得准。
- **合规检查清单**：尺寸、背景、商品占比、留白、文字字数、文件体积逐项打勾，不合规直接标红。
- **商品底板自动判断**：透明底 PNG 直接叠进场景；白底 JPG 自动垫一张白色圆角卡片，不会露出方方正正的白块。

底部还有「对比图」和「卖点图」两个页面，也接了同一套能力：对比图可以生成深色科技风背景，卖点图的顶部大图区可以生成场景背景。

## 二、想用 AI 生成自定义场景，只需 3 步

现在用的是内置的 8 张场景图。想生成任意场景（比如「奶油风客厅傍晚暖光」），需要开通一个国内的图像生成服务。

**第 1 步：注册并拿钥匙（5 分钟）**

1. 打开 https://cloud.siliconflow.cn
2. 用手机号注册，完成实名
3. 左侧菜单点「API 密钥」→「新建 API 密钥」→ 复制那串 `sk-` 开头的字符

**第 2 步：把钥匙交给工作台**

1. 打开项目文件夹里的 `.env.local` 文件（用记事本或文本编辑）
2. 找到 `DESIGN_IMAGE_API_KEY=` 这一行，等号后面粘贴刚才复制的密钥
3. 保存，然后重启工作台（关掉终端窗口，重新双击「启动工作台」）

**第 3 步：确认能用**

打开主图工作室 → 切到「场景副图」→ 点「AI 生成」页签 → 点「测试连接」。
看到「连接正常」就说明通了。

## 三、花多少钱

| 模型 | 价格 | 什么时候用 |
|---|---|---|
| Kolors 快手可图 | **免费** | 默认就是它，日常场景图够用 |
| Z-Image Turbo | 约 0.10 元/张 | 光影和质感明显更好，正式出图推荐 |
| Qwen-Image | 约 0.30 元/张 | 细节最丰富，做高质量详情页 Banner |

一张背景图可以反复用在多个 SKU 上，不是每张主图都要重新生成。按每月出 50 张场景图算，用 Z-Image 大约 5 块钱。

> 提示：同一个页面连点「生成背景」有 4 秒防抖，避免误触重复扣费。

## 四、为什么不让 AI 直接画整张主图

这是刻意这么设计的，行业里做得好的工具（绘蛙、美图设计室、Photoroom）也都是这个思路：

| 让 AI 画整张主图 | 现在的做法 |
|---|---|
| 商品会被重新"想象"，空调外观和实物对不上 | 商品用你的真实照片，AI 碰不到 |
| 中文文案 AI 画出来是乱码或错字 | 文字用 canvas 排版，一字不差 |
| 尺寸、留白、合规规则控制不住 | 每项按京东规范硬约束 + 逐项校验 |
| 一次 0.1-0.3 元，改一个字要重画 | 背景只生成一次，文案随便改 |

**一句话：AI 只负责背景氛围，商品和文字永远由工作台精确合成。**

同理，也刻意没做「按颜色抠图」——空调本身就是白的，白底图上机身和背景的色差只有个位数，色差法一定把机身一起抠掉。要真正抠干净得靠 AI 抠图模型，现在没接。用白卡展台是稳的，也够用。

## 五、常见问题

**Q：生成失败了怎么办？**
先点「测试连接」看 Key 通不通。如果是「余额不足」，去硅基流动控制台充值（新用户有赠送额度）。

**Q：生成的背景里有奇怪的东西？**
换一个模型试试，Z-Image 比免费的 Kolors 听话。也可以点「帮我写描述」，让 AI 把一句话扩写成规范提示词再生成。

**Q：商品图上传后占比显示不出来？**
说明这张图不是透明底也不是纯白底（比如直接拍的生活照）。此时占比只能按整张图估算，建议换成白底图。

**Q：图片会不会上传到外面？**
商品图完全在浏览器本地处理，不出你的电脑。只有「AI 生成背景」这一步会把提示词（纯文字）发出去，不发图片。
