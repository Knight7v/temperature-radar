# 客服质检咨询分类与适用规则 v1

机器仅根据**顾客发言**寻找咨询类别；客服主动提及某产品或优惠，不会据此把顾客咨询归入该类别。同一会话可归入多个类别。未命中明确线索时为“待分类”，由主管在复核页修正。类别由当前聊天原文动态分析，旧会话无需重新导入；主管修正的类别保存在复核记录中。

| 类别 | 典型顾客诉求 | 除通用项外的适用规则 |
| --- | --- | --- |
| 产品选购 | 型号、参数、能效、耗电、尺寸及产品推荐 | 产品与活动信息 |
| 价格优惠 | 价格、优惠券、国补和活动 | 产品与活动信息 |
| 订单物流 | 下单、付款、发货、配送和签收 | 业务流程 |
| 安装售后 | 安装、维修、退换货、保修与收费 | 业务流程；产品与活动信息 |
| 投诉争议 | 投诉、消协、工商、举报等 | 投诉接待 |
| 待分类 | 顾客发言不足以确定诉求 | 显示全部规则，由主管逐项判定适用性 |

通用项包括高压线、一次解决、服务礼仪、回应时间、信息完整性、沟通逻辑、语言表达和服务主动性。类别控制主管**需要完成的评分项**；已确认的评分仍采用现有高压线及 70/30 人工评分规则。机器聊天行为预评分继续单独展示，不替代人工终评。

机器额外计算客服与顾客轮次、首次回复耗时，并定位重复催单话术及产品/政策承诺。这些都是待核对线索，不直接扣分。“十年质保”“安装免费”等陈述必须对照对应产品、咨询日期和有效政策；资料缺失时只能标记“需外部核实”，不能判定客服信息错误。未成交跟进与流失归因需要订单或跨会话数据，本版不对单通聊天自动评分。

当前分类是可复核的关键词候选，不是语义判决；多意图、隐含诉求和指代不清时须由主管修正。后续可用主管已分类的会话校准规则，并在引入版本化产品与政策资料后扩展事实核验。
