# 客服聊天行为机器预评分 v1

系统在确认导入后，对每通会话生成可复算的 **机器预评分**（0–100 分）。历史会话在查看列表和详情时按同一规则补算。机器只检查聊天文本与时间戳可直接定位的行为；主管的逐项复核评分才是最终结果。

| 条件 | 预评分处理 | 异常提醒 |
| --- | ---: | --- |
| 客服发言包含明确侮辱性用语（当前词表见 `lib/quality/machine-score.js`） | 扣 40 分 | 高风险，定位原文，主管核对语境 |
| 顾客消息至其后首次人工回复的最长间隔 120–299 秒 | 扣 5 分 | 核对排班、离线状态和会话背景 |
| 上述最长间隔 ≥300 秒 | 扣 10 分，不与前一档叠加 | 高风险，核对排班、离线状态和会话背景 |
| 顾客提及投诉；客服提及商品、活动、售后承诺 | 不扣分 | 提醒核对后续处理或当时政策 |
| 缺少结束标记、时间冲突等日志异常 | 不扣分 | 提醒核对原始日志 |
| 未识别客服或顾客有效发言 | 不评分 | 高风险/需核查，检查客服识别关键词 |

同一规则只扣一次，分数不低于 0。100 分仅表示未命中当前机器规则，**不代表服务合格**。评分结果保留规则版本、扣分原因、提醒级别和对应消息编号；主管可点击定位原文，结合订单、排班和政策排除误报，并按人工质检规则提交最终评分。

店铺、品牌和组别：导入时可选择店铺，品牌取店铺档案，客服组别按品牌映射为“格力组”或“海尔组”。未选择店铺时，仅在客服名称包含唯一完整店铺名称时自动关联；否则仅按名称推断品牌和组别，店铺标为“未关联店铺”。
